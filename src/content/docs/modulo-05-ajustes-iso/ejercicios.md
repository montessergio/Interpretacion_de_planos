### Ejercicio 1 · Límites

Obtenga los límites (mm) de Ø25 H7 y Ø25 g6.

<details><summary>Ver solución</summary>

H7: +21 / 0 µm → 25.021 y 25.000 mm. g6: −7 / −20 µm → 24.993 y 24.980 mm.

</details>

### Ejercicio 2 · Tipo de ajuste

Para Ø50, clasifique H7/g6, H7/k6 y H7/p6 y dé holguras mínima y máxima.

<details><summary>Ver solución</summary>

H7/g6: +9 a +50 µm → **con holgura**. H7/k6: −18 a +23 µm → **de transición**. H7/p6: −42 a −1 µm → **con interferencia** (apriete 1 a 42 µm).

</details>

### Ejercicio 3 · K7 a mano

Calcule ES y EI de Ø25 K7 con la regla de Δ.

<details><summary>Ver solución</summary>

ei(k) = +2; Δ = IT7 − IT6 = 21 − 13 = 8; ES = −2 + 8 = **+6 µm**; EI = 6 − 21 = **−15 µm**.

</details>

### Ejercicio 4 · Sistema eje base

Un eje h6 de Ø25 debe recibir una pieza con ajuste de transición firme. ¿Qué letra de agujero se emplea y cuáles son sus límites?

<details><summary>Ver solución</summary>

**N7** (preferente de eje base). Para Ø25: ES = −7, EI = −28 µm. Con h6 (0 / −13): holgura mínima = −28 − 0 = −28 µm, máxima = −7 − (−13) = +6 µm.

</details>

### Ejercicio 5 · Montaje térmico

El cubo de acero de un ajuste Ø25 H7/s6 se calienta para montarlo. Apriete máximo = 48 µm. Para obtener 25 µm de holgura de montaje, ¿cuánto debe calentarse? (α = 11.5 × 10⁻⁶ /K)

<details><summary>Ver solución</summary>

Δd = 48 + 25 = 73 µm. Δd/ΔT = 11.5 × 10⁻⁶ × 25 mm = 0.2875 µm/K → ΔT = 73/0.2875 ≈ **254 K** (≈ 274 °C desde 20 °C). Es alto: considere enfriar también el eje o reducir el apriete (p. ej. H7/p6).

</details>
