## Objetivos de aprendizaje

1. Leer una designación como **Ø25 H7/g6** y obtener límites, holguras y tipo de ajuste.
2. Explicar los sistemas de agujero base y eje base y elegir un ajuste preferente según la función.
3. Calcular a mano y con la calculadora las desviaciones ISO de agujeros y ejes.
4. Relacionar el ajuste con el proceso, el montaje (prensa, calor) y el sistema inglés ASME B4.1.
