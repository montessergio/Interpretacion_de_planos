---
title: "Glosario"
description: "Términos de interpretación de planos, tolerancias, ajustes, rugosidad y GD&T con su equivalente en inglés."
---

| Término | Inglés | Definición breve |
|---|---|---|
| Acotación | Dimensioning | Indicación de dimensiones y tolerancias en el plano |
| Agujero base | Basic hole system | Sistema de ajustes con agujero H (EI = 0) |
| Ajuste | Fit | Relación entre agujero y eje que se ensamblan |
| Alabeo circular / total | Circular / total runout | Variación de una superficie al girar sobre un eje de referencia |
| Apriete (interferencia) | Interference | Diferencia negativa entre agujero y eje antes del ensamble |
| Bonus | Bonus tolerance | Tolerancia geométrica adicional al apartarse del MMC/LMC |
| Cajetín | Title block | Recuadro con los datos del plano |
| Chaflán | Chamfer | Arista rebajada |
| Corte (sección) | Section | Vista de la pieza seccionada por un plano |
| Cota de referencia | Reference dimension | Dato informativo entre paréntesis |
| Desviación fundamental | Fundamental deviation | La desviación más próxima a la línea cero |
| Envolvente (Regla n.º 1) | Envelope principle | Forma perfecta a MMC cuando sólo hay tolerancia de tamaño |
| Estrías (lay) | Lay | Dirección predominante del patrón de superficie |
| GD&T | GD&T | Dimensionamiento y tolerancias geométricas |
| Grado IT | IT grade | Grado de tolerancia normalizado (ancho de la zona) |
| Holgura | Clearance | Diferencia positiva entre agujero y eje |
| Línea cero | Zero line | Tamaño nominal en el diagrama de tolerancias |
| MMC / LMC | Max / least material condition | Tamaño con más / menos material |
| Nominal | Nominal size | Tamaño de diseño |
| Ondulación | Waviness | Irregularidad más espaciada que la rugosidad |
| Perfil | Profile | Característica que controla una línea o superficie |
| Posición | Position | Ubicación del elemento respecto de referencias |
| Referencia (datum) | Datum | Elemento teórico exacto del que se miden las ubicaciones |
| RFS | Regardless of feature size | Tolerancia independiente del tamaño real |
| Rugosidad | Roughness | Irregularidades finas de una superficie |
| Sistema de referencias (DRF) | Datum reference frame | Conjunto de referencias que fija la pieza |
| Tolerancia | Tolerance | Variación permitida |
| Vista auxiliar | Auxiliary view | Vista de una cara inclinada en verdadera magnitud |
| Zona de tolerancia | Tolerance zone | Región donde debe estar el elemento |
