## Cómo citar una norma

Siempre: **organismo, número, año/edición, título y estado consultado**.

| Elemento | Ejemplo |
|---|---|
| Norma ISO | ISO 286-1:2010, *Geometrical product specifications (GPS) — ISO code system for tolerances on linear sizes — Part 1*. Vigente a 2026-11-14. |
| Norma ASME | ASME Y14.5-2018 (R2024), *Dimensioning and Tolerancing*. |
| NOM | NOM-026-STPS-2008, *Colores y señales de seguridad e higiene, e identificación de riesgos por fluidos conducidos en tuberías*. DOF 2008-11-25. |
| Libro | Apellido, N. *Título*. Edición. Editorial, año. |

Cuando una norma tenga **enmiendas o correcciones**, cítelas (p. ej. ISO 286-2:2010/Cor 1:2013).

## Cómo citar este repositorio

El archivo `CITATION.cff` genera la cita desde GitHub («Cite this repository»). Ejemplo en prosa:

> Montessergio. *Interpretación de planos* [material de estudio]. Versión 1.0.0, 2026. https://github.com/Montessergio/Interpretacion_de_planos

## Reglas de uso de contenido

- Parafrasee; **no copie** texto de normas, tablas completas ni figuras protegidas.
- Las tablas de este repositorio son **extractos educativos recalculados**; no sustituyen a la norma.
- Si cita una cifra, cite **también** su nivel de verificación (✅ 🟡 ⚠️) o consulte la fuente primaria.
