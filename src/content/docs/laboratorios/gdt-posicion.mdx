## Cómo usarlo

1. Elija agujero o eje, el modificador (MMC, LMC, RFS) y los límites de tamaño.
2. Ingrese el tamaño real y la desviación del centro (x, y).
3. Use la sección de **sujetadores** con agujeros de paso de ISO 273.

## Tecnología y archivos fuente

- **Tecnología:** JavaScript puro + SVG; lógica en `public/labs/_shared/gdt-core.js`, con pruebas en `tests/laboratorios.test.mjs`.
- **Archivo fuente necesario:** Ninguno.
- **Integración en el sitio:** la carpeta `public/labs/gdt-posicion/` se publica tal cual y se incrusta con `<Lab id="gdt-posicion" />`.

## Limitaciones (sitio estático en GitHub Pages)

- Modelo 2D simplificado (posición con zona cilíndrica).
- Las fórmulas de sujetadores suponen despreciable la variación de orientación; confirme el método en la norma vigente.
