## Cómo usarlo

1. Elija un módulo (o todos) y pulse **Comenzar**.
2. Responda, lea la explicación y continúe.
3. Agregue preguntas editando los JSON de `public/labs/quiz/bancos/` sin tocar código.

## Tecnología y archivos fuente

- **Tecnología:** JavaScript puro con bancos de preguntas en **JSON** (`bancos/indice.json` y `modulo-NN.json`) y `localStorage` para el mejor puntaje.
- **Archivo fuente necesario:** Archivos JSON de preguntas: `{ "q": ..., "o": [...], "c": índice, "e": explicación, "n": norma }`.
- **Integración en el sitio:** la carpeta `public/labs/quiz/` se publica tal cual y se incrusta con `<Lab id="quiz" />`.
